# 开口练 · Daily Speak

面向英语初学者和外贸从业者，打开网页就能练英语：**24 课、144 句内置中英对照**，从打招呼到日常交流、出行和外贸入门；听一句、说一句、录音回听。无需自己写内容，也无需配置 AI。

**[打开网页版](https://leidiamren-create.github.io/daily-speak/)** · [GitHub 源码](https://github.com/leidiamren-create/daily-speak)

纯 HTML / CSS / JavaScript，**没有框架、没有运行依赖、没有数据库**。支持手机和电脑，MIT 开源。

## 功能

- **内置课程**：开口第一步、聊聊日常、出门用得上、外贸入门，每类 6 课，每课 6 句，附简短练习提示。
- **直接跟练**：默认打开第一课，支持课程切换、上一课 / 下一课。录音或点击“这句练好了”自动保存进度，不用收藏也能保留课程进度。
- **写中文**：把生活流水账、产品介绍和观点转成自然、简短的口语英文，逐句附中文对照。
- **导入英文**：粘贴英文或上传 UTF-8 `.txt` 文件，自动按标点和换行分句，无需 AI。可勾选用 AI 添加中文对照，保留英文原文。
- **AI 出题**：日常生活、外贸客户接待、产品介绍、直播带货、心情与观点；支持补充场景细节。
- **逐句跟读**：默认曼波音色，内置课程与示例附逐句音频；支持 0.7 / 0.85 / 1 倍语速、单句循环、上一句 / 下一句、隐藏中文。
- **录音回听**：逐句录音、回放、下载，记录已练句子。
- **练习本**：自动保存生成和导入的内容，收藏内置示例，重新打开或删除练习。
- **自带 AI 接口**：填写 OpenAI 兼容接口地址、模型及自己的密钥。
- **可选语音服务**：设备英语、曼波在线 AI 配音、自定义 TTS 接口、GPT-SoVITS 本地或自建模型服务。

内置课程是默认入口，中文改写、英文导入和 AI 出题放在“自定义练习”中。另保留三组口语示例。默认播放随网站保存的曼波音频，不需要浏览器支持语音合成，也不消耗语音生成额度；自己输入或 AI 生成的新句子使用所选语音服务。本版不包含摄像、发音评分或云同步。

## 课程内容

- **开口第一步**：打招呼、介绍自己、请求重复、礼貌用语、数量与时间、身边物品。
- **聊聊日常**：早晨、家人、喜好、天气、心情、周末安排。
- **出门用得上**：饮品、点餐、购物、问路、酒店入住、打车。
- **外贸入门**：展位接待、产品介绍、客户需求、报价、样品与运费、客户跟进。

课程主题参考 [British Council A1 口语](https://learnenglish.britishcouncil.org/free-resources/speaking/a1)、[A1 听力](https://learnenglish.britishcouncil.org/free-resources/listening/a1) 和 [VOA Let's Learn English Level 1](https://learningenglish.voanews.com/p/5644.html) 的入门主题安排。**例句与中文对照为本项目自编，未复制这些机构的教材、录音或视频。** 外贸课为围绕用户需求编写的补充内容；本项目不属于上述机构的官方课程。

课程中的姓名、时间、数量、价格和产品描述均用于练习。对话中的 A、B 表示两名说话人，不会被朗读出来。

第一次打开直接点击“听这一句”即可开始；手机端优先显示跟练区，通过“选课”可跳到课程目录。不用麦克风时，可以自己开口后点击“这句练好了”。

## 本地运行

安装 Node.js 20 或以上版本，在项目目录运行：

```sh
npm start
```

打开 <http://localhost:4173>。无需执行 `npm install`，也没有构建步骤。

手机预览时，让手机和电脑连接同一路由器，将启动命令换为 `npm run start:lan`，再在手机浏览器打开 `http://电脑的局域网IP:4173`。`localhost` 只指当前设备，不能在手机上指向电脑。电脑需保持运行，并允许本地网络访问 4173 端口。

不要直接双击 HTML：浏览器的 ES 模块与录音功能需要通过网页服务访问。局域网的普通 HTTP 地址通常不能使用麦克风；手机请使用 HTTPS 部署。

## 发布到 GitHub Pages

1. 将此目录的全部源文件推送到 GitHub 公开仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 选择 **Deploy from a branch**。
4. 选择 **main** 和 **/ (root)**，点击 **Save**。
5. 等待 GitHub 给出 HTTPS 网址。

页面资源均使用相对路径，可部署在 `https://你的账号.github.io/仓库名/`。根目录的 `.nojekyll` 让 GitHub 直接发布静态文件。也可以将文件上传到其他静态网页托管服务。

## 选择朗读声音

点击跟练区的 **声音** 或右上角 **设置**，选择朗读方式后保存，再点击“听这一句”。

- **曼波 · AI 配音**：默认方式。24 课和 3 组示例的英文均附预存音频，点击即播放；重复播放、刷新页面和换设备都不会调用生成接口。其他新句子通过 MiloraAPI 公开试用接口在线生成，会发送当前英文，无需密钥。服务方目前标注每个 IP 每天 50 次免费生成，额度和可用性可能变化。接口来源：[Manbo TTS 项目说明](https://github.com/xmimu/manbo-tts#api-说明)、[MiloraAPI 接口文档](https://api.milorapart.top/docs/45/mbAIsc)。这是第三方合成音色接入，模型权重没有打包进网页。英语音质与发音需自行试听。
- **设备英语**：选择设备安装的英语声音，无需密钥。浏览器不支持语音合成时，内置内容仍播放已保存的曼波音频；未预存的自定义内容才会提示切换朗读方式。
- **自定义 TTS 接口**：填写 OpenAI 兼容的 `/audio/speech` 基础地址或完整地址、语音模型、音色标识及独立语音密钥。请求使用 `model`、`voice`、`input`、`response_format: "mp3"`，接口直接返回音频。参数参考 [OpenAI 官方语音接口文档](https://developers.openai.com/api/reference/cli/resources/audio/subresources/speech/methods/create)。
- **GPT-SoVITS 本地 / 自建模型**：连接已运行的 `api.py` 服务；该服务预先加载模型与默认参考音频，网页以 `GET ?text=...&text_language=en` 请求语音。`api_v2.py` 的 `/tts` 接口不适用此选项。启动参数参见 [GPT-SoVITS 官方 api.py](https://github.com/RVC-Boss/GPT-SoVITS/blob/main/api.py)。本项目不自动安装推理环境、下载或加载模型权重。

曼波模型的公开检索来源包括 [VOFL 的《赛马娘》曼波/诗歌剧模型页](https://www.vofl.ai/models/fe96daa3-8407-494a-96d8-20e0f6f5344c)；该页面列出 GPT-SoVITS 模型，但本仓库不收录或再分发其权重，也未据此宣称获得模型的商业授权。

所有合成音频均明确标记为 **AI 配音**。内置曼波音频存放在 `audio/manbo/`，由 `audio.js` 将原句映射到文件；可与网页一起部署到 GitHub Pages，访客不需要连接作者电脑。自定义内容在线生成的音频在当前页面会话中缓存，循环、重复播放和调整速度不会重新请求合成；刷新或保存设置会清空这部分缓存。切句、录音、打开设置或切到后台会停止朗读并取消尚未完成的请求。取消客户端请求不代表服务端一定停止合成或不计次数。

预存音频按需加载，不会在打开网页时下载全部课程。网络断开且音频未缓存时不能播放；音频文件缺失或加载失败会明确报错，不会自动消耗在线额度。已有的声音偏好会保留，新用户默认使用曼波。

自定义服务需允许浏览器跨域访问（CORS）。公开网页建议使用 HTTPS 接口。本地 `127.0.0.1` 指访问者自己的设备，并非网站作者的电脑；浏览器可能要求本地网络权限。未运行模型服务时会直接报错，不会偷偷切回设备声音。

## 配置文字 AI

仅在希望自由生成新内容时，点击右上角 **设置 → 自定义 AI（选填）**：

- **API 地址**：填写服务商提供的基础地址（通常以 `/v1` 结尾），也支持完整的 `/chat/completions` 地址。
- **API Key**：自己的密钥；使用不需要认证的本地接口时可以留空。
- **模型名称**：填写服务商提供的确切模型标识。

接口需支持 `POST /chat/completions`、`messages` 输入及 `choices[0].message.content` 输出。模型需按提示返回 JSON。本应用不强制使用 `response_format`，以便兼容更多服务商。

纯前端直接请求你配置的地址，**该服务商需要允许网页的跨域请求（CORS）**，包括 `Content-Type`、`Authorization` 请求头。HTTPS 网页需使用 HTTPS 接口。若服务商不允许浏览器访问，应使用自己控制的兼容接口网关；本项目不提供公共代理，也不会代管密钥。

未配置 AI 时，全部 24 课、英文导入、示例练习、预存音频和录音均可使用。自定义句子默认通过曼波在线试用接口朗读，也可以切换设备英语。接口错误会明确显示，不会把示例伪装成 AI 结果。

## 练习数据与录音

- 练习正文、进度、接口地址、模型和语音偏好存储于当前浏览器的 `localStorage`，清理网站数据会删除它们。
- 内置课程进度单独保存；删除练习本中的课程收藏不会清除这门课的进度。再次点开课程或刷新网页后可继续查看已练句子。
- 文字与语音 API Key 分别存储于当前标签页的 `sessionStorage`；关闭标签页后通常清除，部分浏览器的会话恢复功能可能恢复它。共用设备可在设置中清空密钥后保存。
- 执行 AI 生成或中文对照时，输入内容会发送到你配置的文字接口；播放预存曼波音频只请求本网站的文件。曼波的新句子在线生成、自定义 TTS 或 GPT-SoVITS 播放会将当前英文发送到对应语音服务。使用设备英语不会调用这些外部接口。没有自建后台、统计脚本或远程字体。
- 录音保存在当前页面内存中，不上传服务器。切换句子可以回听本次会话的录音，刷新后清除。需要保留时点击 **下载**。
- 录音时切换句子、切换练习或将页面转入后台会结束并丢弃未完成的录音；先点击 **结束录音** 即可保留。
- 设备朗读的可用声音、音质和是否联网由浏览器与操作系统决定。没有英语声音时，请安装设备英语语音包。
- 播放内置音频只需浏览器支持普通音频播放，不要求 Web Speech API。英文分句使用 `Intl.Segmenter`，录音使用 `MediaRecorder` 和麦克风权限；实际音质与移动端兼容性以设备为准。

## 项目结构

```text
index.html          页面与表单
styles.css          桌面和手机布局
app.js              跟练、朗读、录音、设置和练习本
ai.js               AI 请求与结果解析
tts.js              曼波、自定义 TTS 和 GPT-SoVITS 接口
audio.js            原句与预存曼波音频的对应关系
audio/manbo/        随网站保存的逐句音频
content.js          24 课内置内容、英文分句与示例
scripts/serve.mjs   零依赖本地网页服务
tests/              分句、AI 接口与预存音频检查
```

检查与测试：

```sh
npm run check
npm test
```

测试使用模拟接口，不消耗 AI 额度。改动保持简单直接，代码标识符使用英文，注释使用简短中文，文件统一 UTF-8。

## 练习建议

每天写几句真实发生的事，或者介绍一个实际产品。听清一句后自己录一遍，回听语气和停顿，再试着不看英文说出来。熟悉后换个说法或自己回答客户的问题。学习效果取决于投入与实际交流，不承诺固定时间内达到流利水平。
