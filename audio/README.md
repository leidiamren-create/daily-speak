# 内置曼波音频

24 课与 3 组示例共 156 句，均提供对应的预存音频。默认直接播放网站文件，无需语音合成接口、密钥或浏览器设备朗读支持。

- 音色：曼波，AI 合成配音。
- 来源：[MiloraAPI 曼波配音生成接口](https://api.milorapart.top/docs/45/mbAIsc)。
- 制作日期：2026-10-02。
- 格式：16 kHz、16-bit、单声道 PCM WAV。
- 内容：本项目自编英文；按课合成后，在本地参考词语时间和停顿切成逐句文件，停顿过短的句子独立合成。部分缩写在合成时展开为完整说法。
- 索引：`../audio.js` 将英文原句映射到 `manbo/` 中的文件。文件名是原句 SHA-256 的前 16 位。

只在播放时加载相应句子的音频。用户自己导入或生成的其他句子不会写入此目录。

修改内置英文时，同步制作对应音频并更新索引，再运行 `npm test` 检查覆盖情况。模型权重与制作时使用的工具不属于网站运行依赖。
